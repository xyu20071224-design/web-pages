临时文件传送

把手机上的照片、PDF、压缩包甩给电脑，或者反过来。两台设备直连传输，文件不经过任何服务器，也不留副本。

为什么不是「上传」？ 本站托管在 GitHub Pages，只能提供静态文件（服务器对 POST 直接返回 405），没有任何可以写入的地方。 所以这里的做法是：服务器只帮忙交换一次「牵线信息」，真正的文件在两台设备之间点对点直传。

发送

在本机生成一个房间号，把房间号或链接给另一台设备。

接收

输入发送方显示的房间号，连上之后文件会自动传到这台设备。

等待输入房间号

怎么用

  1. 两台设备都打开本页（同一网址，手机和电脑各开一个）。
  2. 左边点「创建传送房间」，得到 6 位房间号；右半边在另一台设备上填这个号码。 手机扫不了码就直接把链接发给自己也行，链接里带房间号。
  3. 连上后左边选文件、点「开始发送」，右边会自动开始接收，收完点「保存」。
  4. 传完把页面关掉即可，房间随即失效。

文件走 WebRTC DataChannel 直连，本站不存储、不中转、不记录文件名。
两端都不在同一网络且 NAT 严格时可能连不上，此时换用微信/网盘更快。
